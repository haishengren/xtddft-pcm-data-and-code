# xtddft-pcm-data-and-code

Data and calculation files for the study of spin adaptation and nonequilibrium
solvation in radical doublet excitations using X-TDDFT and PCM.

- [inputs/](inputs/): BDF inputs and software information.
- [coordinates/](coordinates/): molecular geometries.
- [data/](data/): numerical results and experimental spectral data.
- [scripts/](scripts/): analysis and figure-generation scripts.

## Software

Electronic-structure calculations were performed using the BDF program package. The build information and software access details are provided in inputs/README.md.
